
Talamis - Language Learning Web Application
A modern, responsive web application designed to help users master new languages through daily lessons, audio practice, and interactive tracking. Built with Angular (Standalone Components, Signals) and a robust .NET backend architecture.

<img width="1273" height="832" alt="Talamis" src="https://github.com/user-attachments/assets/d86c0ec2-2b94-4abf-bfe9-0d5a15b07ff4" />

✨ Features:
Interactive Dashboard: Dynamic greeting utilizing Angular computed signals, streak counters, and daily progress visualization.

Bento Grid Layout: Clean, modular UI displaying active lessons, audio players for listening practice, and goal tracking.

Secure Authentication: User login and registration pages backed by secure token handling and reactive forms.

Modern Styling: Custom responsive design styled with CSS variables, Flexbox, and CSS Grid matching a professional brand identity.

🛠️ Tech Stack
Frontend: Angular (Standalone Components, Signals, ChangeDetectionStrategy.OnPush), TypeScript, HTML5, CSS3.

Backend: .NET Web API, C#, Entity Framework Core, SQL Server.

Tools: Git, GitHub, Swagger UI.
